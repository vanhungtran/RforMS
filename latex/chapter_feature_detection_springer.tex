\begin{abstract}
\noindent
Untargeted high-resolution liquid chromatography--mass spectrometry (LC-MS) datasets in metabolomics, lipidomics, and bottom-up proteomics do not directly yield molecular abundance tables. The primary output of an instrument acquisition is a continuous, noisy three-dimensional data surface spanned by retention time ($t_R$), mass-to-charge ratio ($m/z$), and detector intensity ($I$). Converting raw instrument files into a reproducible, quantitative feature matrix requires rigorous chromatographic peak detection, retention time alignment across runs, correspondence grouping, and iterative gap-filling.

This chapter establishes the analytical chemistry, signal processing, and practical foundations of untargeted LC-MS feature extraction using the modern \texttt{xcms} platform and the Bioconductor \texttt{MSnbase} infrastructure. We formalize the distinction between raw mass spectral peaks and chromatographic features, establish the continuous wavelet transform (CWT) framework and Mexican hat (Ricker) wavelet mechanics for chromatographic apex localization, and formulate the dynamic region-of-interest (ROI) mass-tracking algorithm. We then examine retention time drift, contrasting non-linear dynamic time warping via Ordered Bijective Interpolated Warping (\texttt{obiwarp}) against peak-density LOESS regression. Furthermore, we formalize correspondence grouping via kernel density estimation and formulate the targeted re-integration mechanics of gap-filling (\texttt{fillChromPeaks}) to prevent the fabrication of artificial missing values. The chapter includes a complete, reproducible R laboratory on benchmark datasets, an analysis of the ``Five Deadly Sins'' of feature extraction, a tutor's self-assessment diagnostic checklist, and multi-tier exercises with complete worked solutions.
\end{abstract}

\noindent\textbf{Keywords:} Feature Detection, CentWave, Continuous Wavelet Transform (CWT), Region of Interest (ROI), Retention Time Alignment, Obiwarp, Peak Correspondence, Gap Filling, \texttt{xcms}, Metabolomics.

\begin{notebox}
\textbf{Tutor's Methodological Advice: The Gap-Filling Imperative}\\
Never analyze an untargeted LC-MS feature matrix that has not undergone raw ion gap-filling (\texttt{fillChromPeaks}). When an analyte is present at low concentration, instrumental baseline noise fluctuations will randomly push the signal-to-noise ratio above or below the peak-picking threshold ($\text{S/N} = 10$) across technical replicates. Exporting the peak table without gap-filling manufactures an artificial $15$--$25\%$ missing-data rate for authentic, detected molecules. Gap-filling re-queries the raw spectral data across the consensus retention time and mass window, replacing artificial missingness with genuine low-level physical signal \cite{smith2006xcms, benton2015evaluating}.
\end{notebox}

\section{Introduction: The Anatomy of a High-Resolution LC-MS Data Surface}
% =============================================================================

Modern untargeted liquid chromatography--mass spectrometry systems (e.g., Ultra-High Performance Liquid Chromatography coupled to Quadrupole Time-of-Flight [UHPLC-Q-TOF] or Orbitrap mass spectrometers) generate massive datasets \cite{patti2012metabolomics, aebersold2016mass, want2010global, forcisi2015liquid, boland2023health}. A single 45-minute analytical run contains millions of individual $(m/z, I)$ ion measurements collected across thousands of successive scan cycles.

To perform downstream statistical modeling, machine learning, or differential abundance analysis, this raw three-dimensional data surface $\mathcal{S}(t_R, m/z, I)$ must be mapped onto a discrete two-dimensional quantitative feature matrix:
\begin{equation}
\mathbf{Y} \in \mathbb{R}^{P \times N}
\end{equation}
where each row $p \in \{1, \dots, P\}$ represents an aligned chromatographic feature characterized by an exact $m/z$ and retention time coordinate $(m/z_p, t_{R, p})$, and each column $n \in \{1, \dots, N\}$ represents an analytical sample \cite{mclean2021metabolomics}.

\subsection{Chromatographic Peaks vs. Molecular Features}

A fundamental source of terminology confusion in computational mass spectrometry is the distinction between a \textit{spectral peak}, a \textit{chromatographic peak}, and an \textit{aligned feature}:
\begin{itemize}
    \item \textbf{Spectral Peak (Centroid):} An ion abundance reading at a discrete $m/z$ coordinate in a single mass spectrum acquired at time $t_R$. In profile-mode data, it represents a Gaussian or Lorentzian instrumental peak along the $m/z$ dimension \cite{chambers2012cross}.
    \item \textbf{Chromatographic Peak (EIC Peak):} A continuous chromatographic elution profile formed by an analyte eluting from the analytical column over a finite retention time window $[t_{\text{start}}, t_{\text{end}}]$ at a nearly constant $m/z$. It represents a single chemical entity within a single sample run.
    \item \textbf{Aligned Feature (Correspondence Group):} A cross-sample cluster of chromatographic peaks from multiple analytical runs that share the same $m/z$ within instrumental tolerance and the same retention time after chromatographic drift correction \cite{smith2006xcms}.
\end{itemize}

\section{Signal Processing Mechanics of the CentWave Algorithm}
% =============================================================================

Traditional peak picking algorithms relied on binning or filtering adjacent spectra, suffering severe sensitivity losses in high-resolution datasets where peak shapes vary across three orders of magnitude in dynamic range. To address this, Tautenhahn et al.~\cite{tautenhahn2008highly} developed the \textbf{CentWave} algorithm, which combines dynamic Region-of-Interest (ROI) mass tracing with the Continuous Wavelet Transform (CWT).

\subsection{Mass Accuracy Tolerances and ppm Formulation}

In high-resolution mass spectrometers, mass measurement error is proportional to the target mass $m/z$. The instrumental tolerance is parameterized in parts-per-million ($\text{ppm}$):
\begin{equation}
\label{eq:ppm_def}
\Delta m = \frac{m \cdot \text{ppm}}{10^6} \implies [m - \Delta m, \; m + \Delta m]
\end{equation}
For an Orbitrap instrument operating at $5\text{ ppm}$ tolerance:
\begin{itemize}
    \item At $m/z = 200.000$, $\Delta m = 200 \times 5 \times 10^{-6} = 0.0010\text{ Da} \implies \pm 1.0\text{ mDa}$.
    \item At $m/z = 800.000$, $\Delta m = 800 \times 5 \times 10^{-6} = 0.0040\text{ Da} \implies \pm 4.0\text{ mDa}$.
\end{itemize}

\subsection{Region-of-Interest (ROI) Construction}

CentWave constructs mass traces dynamically across sequential chromatographic scans without static $m/z$ binning \cite{tautenhahn2008highly}:
\begin{enumerate}
    \item \textbf{Seeding Centroids:} The algorithm identifies centroided mass spectral peaks $(m_i, I_i)$ in scan $t$ whose ion intensity exceeds the instrumental baseline noise threshold (\texttt{noise} parameter).
    \item \textbf{Bidirectional Mass-Tracking:} For each candidate centroid, CentWave searches adjacent scans ($t+1, t+2, \dots$) for centroided peaks within the mass tolerance window $[m_i - \Delta m, \, m_i + \Delta m]$ defined by Eq.~(\ref{eq:ppm_def}).
    \item \textbf{ROI Prefiltering (\texttt{prefilter = c(k, I)}):} A candidate mass trace is retained as a valid Region of Interest (ROI) if and only if it spans at least $k$ consecutive scans with centroid intensities exceeding threshold $I$. This eliminates transient electronic spikes and single-scan detector noise while preserving authentic chromatographic elution profiles.
    \item \textbf{Gap Bridging and Boundary Definition:} If a scan lacks a matching centroid within $\pm \Delta m$, the trace is allowed to bridge a user-specified number of missing scans (gap tolerance) before terminating. The resulting ROI defines a contiguous extracted ion chromatogram (EIC) vector $\mathbf{s} = (s(t_1), s(t_2), \dots, s(t_K))$ bounded by exact $m/z$ and retention time limits $[m/z_{\min}, m/z_{\max}] \times [t_{\text{start}}, t_{\text{end}}]$.
\end{enumerate}

\subsection{Continuous Wavelet Transform with the Mexican Hat Wavelet}

Within each extracted ROI $\mathbf{s}(t)$, CentWave applies the Continuous Wavelet Transform (CWT) to locate peak boundaries and apexes across multiple chromatographic scales. The mother wavelet is the normalized Mexican Hat (Ricker) wavelet, mathematically defined as the second derivative of a Gaussian distribution:
\begin{equation}
\label{eq:mexican_hat}
\psi(t) = \frac{2}{\pi^{1/4} \sqrt{3\sigma}} \left( 1 - \frac{t^2}{\sigma^2} \right) e^{-\frac{t^2}{2\sigma^2}}
\end{equation}
The prefactor $\frac{2}{\pi^{1/4} \sqrt{3\sigma}}$ (where $\pi^{1/4}$ sits strictly outside the square root of $3\sigma$) guarantees that the wavelet has unit $L^2$-norm:
\begin{equation}
\label{eq:l2_norm}
\|\psi\|_{L^2}^2 = \int_{-\infty}^{\infty} |\psi(t)|^2 \, dt = 1
\end{equation}

The continuous wavelet transform of the chromatographic signal $s(t)$ at scale (dilation) $a > 0$ and translation (position) $b \in \mathbb{R}$ is defined by the inner product:
\begin{equation}
\label{eq:cwt_integral}
\mathcal{W}_\psi[s](a, b) = \langle s, \psi_{a, b} \rangle = \int_{-\infty}^{\infty} s(t) \, \psi_{a, b}^*(t) \, dt = \frac{1}{\sqrt{a}} \int_{-\infty}^{\infty} s(t) \, \psi\left( \frac{t - b}{a} \right) \, dt
\end{equation}
where $\psi_{a, b}(t) = \frac{1}{\sqrt{a}} \psi\left(\frac{t-b}{a}\right)$. Because the Mexican hat wavelet is strictly real-valued, the complex conjugate satisfies $\psi_{a, b}^*(t) = \psi_{a, b}(t)$. The dilation factor $\frac{1}{\sqrt{a}}$ guarantees energy conservation across scales, ensuring that $\|\psi_{a, b}\|_{L^2} = \|\psi\|_{L^2} = 1$ for all $a > 0$.

\begin{svgraybox}
\textbf{Properties of the Mexican Hat CWT in Peak Detection:}\\
\begin{enumerate}
    \item \textbf{Polynomial Baseline Suppression:} Because $\int_{-\infty}^\infty \psi(t) dt = 0$ and $\int_{-\infty}^\infty t \psi(t) dt = 0$, the Mexican hat wavelet has two vanishing moments. It mathematically annihilates constant chromatographic baselines and linear drifting slopes without requiring separate baseline correction algorithms:
    \begin{equation*}
    s(t) = c_0 + c_1 t \implies \mathcal{W}_\psi[s](a, b) = 0
    \end{equation*}
    \item \textbf{Apex Localization via Zero-Crossings:} The chromatographic apex corresponds to a pronounced local maximum in $\mathcal{W}_\psi[s](a, b)$, while the chromatographic inflection points correspond to zero-crossings of the wavelet transform:
    \begin{equation*}
    \frac{\partial \mathcal{W}_\psi[s](a, b)}{\partial b} = 0, \quad \mathcal{W}_\psi[s](a, b) > \text{Threshold}
    \end{equation*}
    \item \textbf{Scale Matching to Chromatographic Peak Width:} For a Gaussian elution peak with standard deviation $\tau$, the Full Width at Half Maximum is $\text{FWHM} = 2\sqrt{2\ln 2} \, \tau \approx 2.355 \, \tau$. The inflection points of the Mexican hat wavelet at scale $a$ occur at $t = \pm a$ (separation $2a$). Maximum CWT response occurs when the wavelet scale matches the chromatographic peak width:
    \begin{equation*}
    a \approx \frac{\text{FWHM}}{2.355} \quad \left(\text{or } w \approx 2a \text{ between inflection bounds}\right)
    \end{equation*}
    In CentWave, the user specifies the chromatographic peak width range \texttt{peakwidth = c(min, max)} in seconds (e.g., $20$ to $50$ s). The algorithm discretizes this interval into a series of wavelet scales $a \in [a_{\min}, a_{\max}]$, simultaneously resolving sharp metabolite peaks and broader lipid profiles \cite{tautenhahn2008highly}.
\end{enumerate}
\end{svgraybox}

\subsection{Algorithmic Ecosystem: Beyond CentWave}
While CentWave remains the flagship peak detection algorithm within Bioconductor's \texttt{xcms}, untargeted mass spectrometry relies on a rich ecosystem of complementary open-source platforms. Key computational frameworks include MZmine 2 and MZmine 3 \cite{pluskal2010mzmine, schmid2023mzmine}, which implement modular grid-based and wavelet peak pickers; OpenMS \cite{rost2016openms}, providing high-performance C++ algorithmic primitives; MS-DIAL \cite{tsugawa2015msdial}, specializing in data-independent acquisition (DIA) and lipidomic deconvolution; and Skyline \cite{maclean2010skyline}, which excels in targeted peak integration and quality auditing. Modern workflows leverage standardized mzML architectures to manage large multi-file cohorts across these diverse engines \cite{rivas2016moving, chambers2012cross}.

\section{Retention Time Alignment: Dynamic Warping vs. Peak Density LOESS}
% =============================================================================

Even with high-precision UHPLC pumps, liquid chromatography experiences systematic and non-linear retention time shifts across sample batches due to column stationary phase degradation, ambient temperature fluctuations, and mobile phase evaporation \cite{mahieu2016warping, dunn2011mass}. 

\subsection{Ordered Bijective Warping (Obiwarp)}

The \texttt{obiwarp} algorithm (Prince \& Marcotte~\cite{prince2006chromatographic}) aligns chromatographic runs directly from complete profile-mode matrices without requiring prior peak detection. It uses dynamic time warping (DTW) with local slope and bijection constraints to align a query run $S_1$ against a selected reference run $S_0$.

Let $\mathbf{M}_0 \in \mathbb{R}^{T_0 \times K}$ and $\mathbf{M}_1 \in \mathbb{R}^{T_1 \times K}$ denote the binned profile matrices for reference and query runs, where each row $\mathbf{m}_i$ represents an $m/z$-binned spectrum vector at retention time scan $i$ (with mass resolution parameterized by \texttt{binSize}). The alignment path $\phi = (\phi_0(k), \phi_1(k))$ optimizes the cumulative similarity matrix $\mathbf{D} \in \mathbb{R}^{T_0 \times T_1}$ via dynamic programming.

Eq.~(\ref{eq:obiwarp_recurrence}) illustrates the foundational dynamic programming recurrence underlying Ordered Bijective Interpolated Warping \cite{prince2006chromatographic}:
\begin{equation}
\label{eq:obiwarp_recurrence}
D(i, j) = \text{response} \cdot \operatorname{Sim}(\mathbf{m}_{0, i}, \mathbf{m}_{1, j}) + \max \begin{cases} 
D(i-1, j-1) - w_{\text{diag}}, \\ 
D(i-1, j) - w_{\text{gap}}(l), \\ 
D(i, j-1) - w_{\text{gap}}(l) 
\end{cases}
\end{equation}
While classical DTW performs an unconstrained pairwise alignment, \texttt{obiwarp} implements four critical algorithmic features tailored to chromatographic spectra:
\begin{itemize}
    \item \textbf{Vector Spectral Similarity (\texttt{distFun}):} The similarity $\operatorname{Sim}(\mathbf{m}_{0, i}, \mathbf{m}_{1, j})$ is computed by vector correlation across $m/z$ bins. In \texttt{xcms}, the parameter \texttt{distFun = "cor\_opt"} computes optimized Pearson cross-correlation, while \texttt{"cor"} and \texttt{"cov"} provide standard correlation or covariance.
    \item \textbf{Affine Gap Penalties (\texttt{gapInit}, \texttt{gapExtend}):} Rather than a constant penalty, time-stretching or compression across $l$ consecutive non-diagonal steps incurs an affine cost $w_{\text{gap}}(l) = \text{gapInit} + (l - 1) \cdot \text{gapExtend}$.
    \item \textbf{Response Weighting (\texttt{response}):} The \texttt{response} parameter balances the relative influence of spectral similarity against warping penalties, transitioning smoothly from rigid near-linear alignment to flexible non-linear drift correction.
    \item \textbf{Local Slope and Bijection Constraints:} To prevent unphysical chromatographic folding or extreme plateaus (where many distinct chemical peaks are compressed into a single scan), \texttt{obiwarp} restricts allowable transitions to local step slopes satisfying $\frac{1}{2} \le \frac{\Delta j}{\Delta i} \le 2$, and computes sub-scan retention time shifts via continuous piecewise linear interpolation \cite{prince2006chromatographic}.
\end{itemize}

\subsection{Peak Groups and Kernel Density LOESS Alignment}

In contrast to full-matrix warping, the \texttt{PeakGroups} algorithm aligns runs by identifying a subset of high-confidence, well-behaved features (``hook peaks'') present in all samples. For each sample $k$, the retention time deviation $\Delta t_R = t_{R, \text{observed}} - t_{R, \text{reference}}$ is modeled as a smooth non-linear function of time using Local Polynomial Regression (LOESS):
\begin{equation}
\label{eq:loess_alignment}
\Delta t_R(t) = \operatorname{LOESS}(t_R, \; \operatorname{span} = \alpha)
\end{equation}
The corrected retention time is then adjusted as $t_{R, \text{aligned}} = t_R - \Delta t_R(t)$ \cite{smith2006xcms}.

\section{Peak Correspondence and the Mechanics of Gap-Filling}
% =============================================================================

\subsection{Density-Based Grouping (\texttt{groupChromPeaks})}

After retention time alignment, chromatographic peaks across all samples are clustered into features using the \texttt{PeakDensity} algorithm. For each narrow $m/z$ slice (determined by \texttt{binSize}), the algorithm estimates the probability density of retention times across all samples using Gaussian kernel density estimation:
\begin{equation}
\label{eq:kde_rt}
\hat{f}(t) = \frac{1}{n_{\text{peaks}} h} \sum_{i=1}^{n_{\text{peaks}}} K\left( \frac{t - t_{R, i}}{h} \right), \quad K(u) = \frac{1}{\sqrt{2\pi}} e^{-u^2/2}
\end{equation}
where $h$ is the bandwidth parameter (\texttt{bw}, typically 2--5 seconds for UHPLC). Valleys where $\hat{f}(t)$ drops below a threshold define the boundaries of individual features. A valid feature must contain peaks from at least a fraction of samples within at least one experimental group (parameter \texttt{minFraction}, typically $\ge 0.50$) \cite{mclean2021metabolomics}.

\subsection{Gap-Filling (\texttt{fillChromPeaks}): Mitigating Artificial Missingness}

In untargeted omics, if an analyte is present at low abundance in sample $k$, CentWave may fail to trigger an automated peak detection if baseline noise pushes the signal slightly below the signal-to-noise threshold ($\text{S/N} < 10$). By default, \texttt{xcms::featureValues()} assigns \texttt{NA} to samples where a feature was not picked. Leaving these entries as \texttt{NA} (or naively imputing them with zero, which is itself a flawed practice) manufactures an artificial $15$--$25\%$ missing-data rate for authentic, detected molecules, severely distorting downstream statistical imputation and differential abundance testing (Chapter 19).

To eliminate this artifact, the \texttt{fillChromPeaks} algorithm executes targeted re-integration across the raw data surface:
\begin{equation}
\label{eq:gap_fill}
\hat{A}_{p, k} = \int_{t_{R, \min}^{(p)}}^{t_{R, \max}^{(p)}} \int_{m/z_{\min}^{(p)}}^{m/z_{\max}^{(p)}} I_k(t_R, m/z) \; d(m/z) \; dt_R
\end{equation}
where $I_k(t_R, m/z)$ denotes the raw detector ion intensity surface of sample $k$, $[t_{R, \min}^{(p)}, t_{R, \max}^{(p)}]$ is the consensus retention time window established by the correspondence feature group $p$, and $[m/z_{\min}^{(p)}, m/z_{\max}^{(p)}]$ is the consensus mass bounding box across the cohort. By querying the raw instrumental files directly at these coordinates, \texttt{fillChromPeaks} replaces artificial \texttt{NA}s with genuine, low-level integrated ion flux or physical baseline background measurements \cite{benton2015evaluating, gieling2020assessment}.

\subsection{Downstream Annotation and Spectral Deconvolution}

Following peak correspondence and gap-filling, feature matrices undergo isotopic and adduct grouping to reconstruct pseudo-spectra corresponding to individual chemical metabolites. Tools such as CAMERA \cite{kuhl2012camera} and RAMClustR \cite{broeckling2014ramclustr} cluster co-eluting features based on chromatographic peak shape correlation and exact mass differences ($\Delta m = 1.00335\text{ Da}$ for $^{13}\text{C}$, $+21.9820\text{ Da}$ for $[M+\text{Na}]^+ - [M+\text{H}]^+$). Denoising algorithms with isotopic credentialing \cite{huan2015denoising} remove background artifacts. Deconvolved spectra are subsequently queried against public repositories or annotated using retention time indexing \cite{domingo2018automated}, pseudomass decomposition \cite{stravs2013automatic}, and deep combinatorial fragmentation trees via SIRIUS 4 \cite{duhrkop2019sirius}.

\section{Hands-On R Laboratory: End-to-End Feature Detection Workflow}
% =============================================================================

We now execute an end-to-end, reproducible R laboratory using \texttt{xcms} (version $\ge 4.0$) and \texttt{MSnbase} \cite{gatto2012msnbase}. We process a 4-sample untargeted LC-MS dataset comparing knockout (\texttt{KO}) and wild-type (\texttt{WT}) metabolomic profiles from the canonical \texttt{faahKO} dataset. Note that CentWave requires centroided mass spectra; if raw instrument files are acquired in continuous profile mode, peak centroiding must first be performed during vendor export (e.g., via ProteoWizard \texttt{msconvert} with peak-picking filters) or within R using \texttt{MSnbase::pickPeaks()} prior to ROI construction. The NetCDF files in \texttt{faahKO} are pre-centroided, and the feature detection metrics reported below illustrate the typical throughput of this standard benchmark cohort.

\section{The Five Deadly Sins of Feature Extraction}
% =============================================================================

\begin{pitfallbox}
\textbf{Deadly Sin 1: Universal Borrowing of CentWave Parameters}\\
\textit{Mechanism:} Blindly copying \texttt{ppm = 25} and \texttt{peakwidth = c(20, 50)} across different instruments (e.g., using Q-TOF parameters on a high-field Orbitrap Exploris 480) \cite{tautenhahn2008highly}.\\
\textit{Mathematical Failure:} An Orbitrap operating at 120,000 resolution has mass accuracy $< 3\text{ ppm}$. Setting $\text{ppm} = 25$ causes mass traces from adjacent isobaric ions or isotopic envelopes to coalesce into single contaminated ROIs, distorting isotope fidelity and inflating peak widths.\\
\textit{Remedy:} Empirically measure mass errors and chromatographic peak widths on calibration standards for each specific LC gradient and mass spectrometer.
\end{pitfallbox}

\begin{pitfallbox}
\textbf{Deadly Sin 2: Setting the ppm Window Too Narrow}\\
\textit{Mechanism:} Configuring $\text{ppm} = 1.0$ on an instrument with thermal detector drift of $3\text{ ppm}$ \cite{mclean2021metabolomics}.\\
\textit{Mathematical Failure:} If mass error drifts by $2\text{ ppm}$ between adjacent scans, the ROI tracking algorithm terminates prematurely, fragmenting a single elution profile into multiple fragmented micro-peaks and splitting features across columns.\\
\textit{Remedy:} Set \texttt{ppm} slightly higher than the 95th percentile of observed mass errors across quality control injections.
\end{pitfallbox}

\begin{pitfallbox}
\textbf{Deadly Sin 3: Skipping Retention Time Alignment on Long Cohorts}\\
\textit{Mechanism:} Attempting to group features across 100 samples directly using a wide retention time window (\texttt{bw = 30}) without prior alignment \cite{mahieu2016warping}.\\
\textit{Mathematical Failure:} A wide correspondence bandwidth groups chemically distinct isomers that elute 15--20 seconds apart into the same false feature, generating contaminated chimeric peaks with scrambled biological quantification.\\
\textit{Remedy:} Always align retention times (\texttt{adjustRtime}) first. Set correspondence bandwidth according to post-alignment chromatographic jitter: typically $\le 5\text{ s}$ for UHPLC gradients, and $10$--$15\text{ s}$ for longer, traditional HPLC runs.
\end{pitfallbox}

\begin{pitfallbox}
\textbf{Deadly Sin 4: Omitting the Gap-Filling (\texttt{fillChromPeaks}) Step}\\
\textit{Mechanism:} Exporting \texttt{featureValues(data\_grouped)} directly without re-integrating missing values \cite{benton2015evaluating}.\\
\textit{Mathematical Failure:} An authentic analyte present at modest intensity will randomly fall below the automated detection threshold ($\text{S/N} \ge 10$) in 10--20\% of samples due to stochastic baseline fluctuations. By default, \texttt{xcms::featureValues()} assigns \texttt{NA} to samples where a peak was not detected. Leaving these as \texttt{NA}s (or naively imputing them with zero) manufactures artificial missingness that misleads downstream imputation models, distorts empirical Bayes moderation, and deflates statistical power.\\
\textit{Remedy:} Always execute \texttt{fillChromPeaks()} to re-integrate background raw detector signal for unpicked samples, replacing artificial \texttt{NA}s with genuine, low-level integrated ion flux.
\end{pitfallbox}

\begin{pitfallbox}
\textbf{Deadly Sin 5: Profile-Mode Memory Exhaustion}\\
\textit{Mechanism:} Loading 100 high-resolution raw LC-MS files into active RAM in in-memory mode (\texttt{mode = "inMemory"}) \cite{gatto2012msnbase}.\\
\textit{Mathematical Failure:} Uncompressed profile-mode spectra typically consume $1$--$3\text{ GB}$ per run depending on scan rate and acquisition range. A cohort of 100 files can require $100$--$300\text{ GB}$ of RAM, triggering system paging, disk thrashing, and fatal out-of-memory crashes.\\
\textit{Remedy:} Always process files using \texttt{readMSData(..., mode = "onDisk")}, where spectral data are retrieved dynamically on-demand from disk.
\end{pitfallbox}

\subsection*{Solution to Exercise 8.1: Instrumental ppm Mass Windows}

\paragraph{Part 1: Absolute Tolerance Windows ($\Delta m$):}
From Eq.~(\ref{eq:ppm_def}):
\begin{equation*}
\Delta m = m/z \times \frac{\text{ppm}}{10^6} = m/z \times 5 \times 10^{-6}
\end{equation*}
\begin{itemize}
    \item \textbf{Metabolite A ($m/z = 89.0244$):}
    \begin{equation*}
    \Delta m_A = 89.0244 \times 5 \times 10^{-6} = 0.000445\text{ Da} = \mathbf{0.445\text{ mDa}}
    \end{equation*}
    Acceptable window: $[89.02396, \; 89.02485]$.
    \item \textbf{Metabolite B ($m/z = 215.0328$):}
    \begin{equation*}
    \Delta m_B = 215.0328 \times 5 \times 10^{-6} = 0.001075\text{ Da} = \mathbf{1.075\text{ mDa}}
    \end{equation*}
    Acceptable window: $[215.03172, \; 215.03388]$.
    \item \textbf{Metabolite C ($m/z = 760.5851$):}
    \begin{equation*}
    \Delta m_C = 760.5851 \times 5 \times 10^{-6} = 0.003803\text{ Da} = \mathbf{3.803\text{ mDa}}
    \end{equation*}
    Acceptable window: $[760.58130, \; 760.58890]$.
\end{itemize}

\paragraph{Part 2: Resolving Isobaric Lipids:}
The mass difference between the two lipid isomers is:
\begin{equation*}
\Delta m_{\text{actual}} = 760.5910 - 760.5851 = 0.0059\text{ Da} = 5.9\text{ mDa}
\end{equation*}
At $m/z = 760.5851$, the $5\text{ ppm}$ half-width is $\Delta m = 3.803\text{ mDa}$. The total window diameter is $2 \Delta m = 7.606\text{ mDa}$.
Because $\Delta m_{\text{actual}} = 5.9\text{ mDa} > \Delta m = 3.803\text{ mDa}$, their individual tolerance windows do not contain each other's apexes. However, their window boundaries overlap slightly:
\begin{align*}
\text{Window}_1 &= [760.5813, \; 760.5889] \\
\text{Window}_2 &= [760.5872, \; 760.5948]
\end{align*}
Because the windows overlap between $760.5872$ and $760.5889$, a setting of $5\text{ ppm}$ risks co-tracing both ions into a single chimeric ROI. To cleanly resolve them, the instrumental tolerance must be tightened to:
\begin{equation*}
\text{ppm}_{\text{req}} < \frac{\Delta m_{\text{actual}} / 2}{m/z} \times 10^6 = \frac{0.00295}{760.585} \times 10^6 \approx \mathbf{3.88\text{ ppm}}
\end{equation*}

\subsection*{Solution to Exercise 8.2: Mexican Hat Wavelet Moments and $L^2$-Normalization}

\paragraph{Part 1: Proof that $\int_{-\infty}^\infty \psi(t) dt = 0$:}
The Mexican hat wavelet is the negative second derivative of a Gaussian:
\begin{equation*}
g(t) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{t^2}{2\sigma^2}} \implies \psi(t) = -C' \frac{d^2 g(t)}{dt^2}
\end{equation*}
Integrating directly:
\begin{equation*}
\int_{-\infty}^\infty \psi(t) dt = -C' \int_{-\infty}^\infty \frac{d^2 g(t)}{dt^2} dt = -C' \left[ \frac{d g(t)}{dt} \right]_{-\infty}^\infty
\end{equation*}
The first derivative of the Gaussian is:
\begin{equation*}
\frac{d g(t)}{dt} = -\frac{t}{\sigma^2} g(t)
\end{equation*}
Evaluating at limits:
\begin{equation*}
\lim_{t \to \infty} \left( -\frac{t}{\sigma^2} e^{-\frac{t^2}{2\sigma^2}} \right) = 0, \quad \lim_{t \to -\infty} \left( -\frac{t}{\sigma^2} e^{-\frac{t^2}{2\sigma^2}} \right) = 0
\end{equation*}
Thus:
\begin{equation*}
\int_{-\infty}^\infty \psi(t) dt = -C' (0 - 0) = \mathbf{0}
\end{equation*}

\paragraph{Part 2: Proof that $\int_{-\infty}^\infty t \psi(t) dt = 0$:}
Notice that $\psi(t)$ is an \textbf{even function} of $t$: $\psi(-t) = \psi(t)$.
Therefore, the integrand $f(t) = t \psi(t)$ is an \textbf{odd function}:
\begin{equation*}
f(-t) = (-t) \psi(-t) = -t \psi(t) = -f(t)
\end{equation*}
The integral of any continuous odd function over a symmetric domain $(-\infty, \infty)$ vanishes identically:
\begin{equation*}
\int_{-\infty}^\infty t \psi(t) dt = \mathbf{0}
\end{equation*}

\paragraph{Part 3: Baseline Drift Suppression:}
Let chromatographic signal with linear baseline drift be $s(t) = c_0 + c_1 t + p(t)$, where $p(t)$ is the true chemical elution peak.
The CWT convolution is:
\begin{align*}
\mathcal{W}_\psi[s](a, b) &= \frac{1}{\sqrt{a}} \int_{-\infty}^\infty \left[ c_0 + c_1 t + p(t) \right] \psi\left(\frac{t-b}{a}\right) dt \\
&= \frac{c_0}{\sqrt{a}} \int \psi(u) a du + \frac{c_1}{\sqrt{a}} \int (a u + b) \psi(u) a du + \mathcal{W}_\psi[p](a, b) \\
&= 0 + 0 + \mathcal{W}_\psi[p](a, b) = \mathcal{W}_\psi[p](a, b)
\end{align*}
The linear baseline slope and constant offset contribute zero to the transform, leaving the wavelet coefficients purely reflective of the chromatographic peak.

\paragraph{Part 4: Derivation of the $L^2$-Normalization Constant ($C$):}
For $\psi(t)$ to be an energy-normalized mother wavelet in $L^2(\mathbb{R})$, its squared norm must satisfy:
\begin{equation*}
\|\psi\|_{L^2}^2 = \int_{-\infty}^\infty |\psi(t)|^2 dt = C^2 \int_{-\infty}^\infty \left( 1 - \frac{t^2}{\sigma^2} \right)^2 e^{-\frac{t^2}{\sigma^2}} dt = 1
\end{equation*}
Substitute the change of variables $u = \frac{t}{\sigma}$, so $t = \sigma u$ and $dt = \sigma du$:
\begin{equation*}
\|\psi\|_{L^2}^2 = C^2 \sigma \int_{-\infty}^\infty \left( 1 - 2u^2 + u^4 \right) e^{-u^2} du
\end{equation*}
Using standard Gaussian definite integrals:
\begin{align*}
\int_{-\infty}^\infty e^{-u^2} du &= \sqrt{\pi} \\
\int_{-\infty}^\infty u^2 e^{-u^2} du &= \frac{1}{2}\sqrt{\pi} \\
\int_{-\infty}^\infty u^4 e^{-u^2} du &= \frac{3}{4}\sqrt{\pi}
\end{align*}
Combining these yields:
\begin{equation*}
\int_{-\infty}^\infty \left( 1 - 2u^2 + u^4 \right) e^{-u^2} du = \sqrt{\pi} - 2\left(\frac{1}{2}\sqrt{\pi}\right) + \frac{3}{4}\sqrt{\pi} = \frac{3}{4}\sqrt{\pi}
\end{equation*}
Equating to unity:
\begin{equation*}
C^2 \sigma \left( \frac{3\sqrt{\pi}}{4} \right) = 1 \implies C^2 = \frac{4}{3\sigma\sqrt{\pi}} \implies C = \frac{2}{\pi^{1/4}\sqrt{3\sigma}}
\end{equation*}
This establishes the exact $L^2$-normalization constant in Eq.~(\ref{eq:mexican_hat}), with $\pi^{1/4}$ sitting unambiguously outside the square root of $3\sigma$.

\subsection*{Solution to Exercise 8.3: Dynamic Time Warping and Obiwarp Mechanics}

\paragraph{Part 1: Dynamic Time Warping Recurrence and Penalties:}
The DTW score recurrence is given by Eq.~(\ref{eq:obiwarp_recurrence}).
\begin{itemize}
    \item \textbf{Diagonal Step Penalty ($w_{\text{diag}}$):} Penalizes simultaneous advancement in both sample and reference runs ($i \to i+1, j \to j+1$). When $w_{\text{diag}} = 0$, linear matching is favored.
    \item \textbf{Gap Penalty ($w_{\text{gap}}$):} Penalizes horizontal ($i \to i+1, j$) or vertical ($i, j \to j+1$) steps, representing chromatographic expansion or compression. A high $w_{\text{gap}}$ prevents excessive warping, while a low $w_{\text{gap}}$ allows the algorithm to adapt to severe non-linear gradient fluctuations.
\end{itemize}

\paragraph{Part 2: The Bijection Constraint:}
Standard dynamic time warping allows multiple query points to map to a single reference point (a vertical or horizontal plateau in the alignment path). In chromatography, this corresponds to mapping multiple distinct chemical elution events into a single time point. \texttt{obiwarp} enforces a local slope constraint ($\frac{1}{2} \le \frac{\Delta j}{\Delta i} \le 2$), guaranteeing that time flows monotonically and bijectively, preventing non-physical temporal fold-overs \cite{prince2006chromatographic}.

\begin{rchunk}{Production-Grade Feature Quality Filter}
filter_high_quality_features <- function(feature_mat, sample_classes, 
                                        max_na_fraction = 0.20, max_qc_cv = 0.30) {
  # 1. Input Validation
  stopifnot(is.matrix(feature_mat), length(sample_classes) == ncol(feature_mat))
  initial_features <- nrow(feature_mat)
  
  # 2. Filter by Missing Value Fraction Across Cohort
  # In untargeted LC-MS feature tables, zeros and NAs represent non-detects below LOD
  na_frac <- apply(feature_mat, 1, function(x) mean(is.na(x) | x == 0))
  pass_na <- na_frac <= max_na_fraction
  
  # 3. Filter by Technical Coefficient of Variation in QC Samples (if present)
  qc_indices <- which(sample_classes == "QC")
  if (length(qc_indices) >= 3) {
    qc_mat <- feature_mat[, qc_indices, drop = FALSE]
    qc_mean <- rowMeans(qc_mat, na.rm = TRUE)
    qc_sd   <- apply(qc_mat, 1, sd, na.rm = TRUE)
    # Avoid division by zero: requires positive mean
    qc_cv   <- ifelse(qc_mean > 0, qc_sd / qc_mean, Inf)
    pass_cv <- is.finite(qc_cv) & (qc_cv <= max_qc_cv)
  } else {
    message("Fewer than 3 QC samples detected; skipping technical CV filter.")
    pass_cv <- rep(TRUE, initial_features)
  }
  
  # 4. Retain Intersection
  retained_idx <- which(pass_na & pass_cv)
  filtered_mat <- feature_mat[retained_idx, , drop = FALSE]
  
  cat(sprintf("[STATUS: COMPLETE] Filtered %d features -> %d retained (%.1f%% pass rate).\n",
              initial_features, nrow(filtered_mat), nrow(filtered_mat) / initial_features * 100))
  cat(sprintf("Excluded for excessive missingness (> %.0f%%): %d features.\n",
              max_na_fraction * 100, sum(!pass_na)))
  if (length(qc_indices) >= 3) {
    cat(sprintf("Excluded for excessive QC CV (> %.0f%%): %d features.\n",
                max_qc_cv * 100, sum(pass_na & !pass_cv)))
  }
  return(filtered_mat)
}
