21  Modeling Covariates and Repeated Measures for MS Data

  • Show All Code
  • Hide All Code
  • View Source

“A two‑group t‑test is rarely enough. Real MS experiments have batches, paired samples, and repeated measurements. Ignoring these structures inflates false positives and invalidates statistical inference.”

Real mass spectrometry studies are intrinsically structured: identical biological replicates sampled longitudinally across a metabolic transition, cell lines processed in distinct instrument batches, and clinical covariates (age, sex, BMI) confounding primary experimental factors. Treating correlated, repeated measurements as independent samples artificially deflates standard errors, creates pseudoreplication, and manufactures spurious discoveries. This chapter demonstrates how to formally model experimental structure using linear mixed-effects models, variance partitioning, and empirical Bayes shrinkage in R—transforming raw longitudinal MS data into robust, reproducible biological conclusions.

WarningThe One Mistake to Avoid

Treating repeated measures as independent samples (pseudoreplication). Paired or longitudinal data analyzed as if independent inflates nominal degrees of freedom, severely narrows confidence intervals, and drives false-positive rates beyond 50%. Always account for intra-subject or intra-replicate correlation using random intercepts, blocking, or specialized covariance structures.

21.2 Why Modeling Structure Matters for MS Data

Mass spectrometry experiments rarely conform to simple independent two-group comparisons. In real cohorts, variance arises from multiple biological and technical strata:

Structure Example in MS Proteomics/Metabolomics Ignoring It Causes
Batch effects Samples run across different instrument days or LC columns Spurious biomarker discoveries confounded by run order
Paired design Identical patient sampled before and after therapeutic intervention Loss of statistical power; between-subject heterogeneity unmodeled
Repeated measures 10-timepoint metabolic transition time-course across biological replicates Severe pseudoreplication; inflated type-I error (p-value deflation)
Confounders Age, sex, and body mass index in clinical biofluids Biased effect size estimates for primary disease contrasts
Factorial design Genotype × Time or Drug × Dose interactions Failure to detect conditional kinetics (e.g., drug active only at late times)

21.2.1 The Intraclass Correlation Coefficient (ICC)

When individual biological units (patients, cultures, animals) are measured repeatedly across T time points, intra-subject observations share baseline variance. The Intraclass Correlation Coefficient (ICC) quantifies the proportion of total variance attributable to between-subject differences:

\rho = \frac{\sigma^2_b}{\sigma^2_b + \sigma^2_e}

where \sigma^2_b denotes the between-subject variance and \sigma^2_e represents within-subject residual noise.

For example, in a cohort of N = 10 patients sampled at T = 4 timepoints (n_{\text{total}} = 40) with an ICC of \rho = 0.60, the effective sample size is only:

n_{\text{eff}} = \frac{40}{1 + 3(0.60)} = \frac{40}{2.80} \approx 14.3

An unblocked naive t-test assumes 38 degrees of freedom (n_{\text{total}} - 2), whereas the true effective sample size supports only \sim 12 (n_{\text{eff}} - 2). The \sim 26 excess degrees of freedom represent severe statistical inflation, severely narrowing confidence intervals and producing falsely significant discoveries.

21.2.2 Linear Mixed Models (LMM) vs. GEE

Two principal paradigms exist for handling correlated MS data:

Criterion Linear Mixed-Effects Models (lme4, dream) Generalized Estimating Equations (geepack)
Inference Target Subject-specific (conditional) Population-averaged (marginal)
Missing Data Valid under Missing at Random (MAR) Requires Missing Completely at Random (MCAR)
Small Samples Exact small-sample degrees-of-freedom corrections (Kenward-Roger) Requires large cluster counts (n \ge 30) for sandwich variance stability
High-Throughput Integrated with Empirical Bayes moderation (variancePartition::dream) Computationally cumbersome across thousands of features

For mass spectrometry, linear mixed-effects models moderated by empirical Bayes are the gold standard.

NoteMethodological Note: Biological Replicates vs. Repeated Measures on Living Subjects

In clinical trials, repeated measures typically arise from the same living individual sampled non-destructively over time (e.g., sequential plasma draws). Persistent intra-subject correlation (\rho > 0) causes classical pseudoreplication if ignored.

In microbial and cell-culture proteomics (such as the Picotti et al. SRM dataset), sampling across a time course is inherently destructive (parallel cultures grown and harvested at each timepoint). Here, the SUBJECT variable represents independent parallel biological cultures (ReplA, ReplB, ReplC). Specifying (1 | SUBJECT) thus models biological replicate baseline heterogeneity (a random blocking effect across the 10 time points), rather than serial within-organism autocorrelation. When cultures are tightly controlled, replicate variance is close to zero (as observed for IDHC); when culture-to-culture drift or instrument batch offsets exist, (1 | SUBJECT) absorbs this baseline variation without consuming fixed degrees of freedom.

21.7 Step 3: Repeated Measures Modeling with variancePartition::dream

In standard linear models, degrees of freedom are N - p. In repeated-measures mixed models with small cluster counts, exact distributions do not exist. The Kenward-Roger (KR) adjustment computes an adjusted covariance matrix for fixed effects that accounts for small-sample variance-component estimation error and derives Satterthwaite-type effective degrees of freedom.

The dream engine in variancePartition (Hoffman & Roussos, 2021) fits linear mixed models across all proteins in parallel, applying Kenward-Roger DDF and borrowing information across features via Empirical Bayes shrinkage.

Code 
# Formula with fixed timepoints and random replicate intercept
form <- ~ 0 + Time_fac + (1 | SUBJECT)

# Formulate contrasts for key transitions using makeContrastsDream:
# Diauxic Shift (T7 vs T1) and Stationary Phase (T10 vs T1)
L <- makeContrastsDream(form, meta_df, 
                        contrasts = c(Diauxic_T7_vs_T1     = "Time_fac7 - Time_fac1",
                                      Stationary_T10_vs_T1 = "Time_fac10 - Time_fac1"))

# Fit dream mixed model with Kenward-Roger DDF
fit_mm <- dream(expr_mat, form, meta_df, L = L, ddf = "Kenward-Roger")
fit_eb <- eBayes(fit_mm)

# Extract differential abundance for Diauxic Shift
res_diauxic   <- variancePartition::topTable(fit_eb, coef = "Diauxic_T7_vs_T1", number = Inf)
res_stationary <- variancePartition::topTable(fit_eb, coef = "Stationary_T10_vs_T1", number = Inf)

21.8 Step 4: Comparing Covariance Structures in nlme

In longitudinal studies, observations close in time are often more correlated than observations distant in time. A standard random-intercept model imposes Compound Symmetry (CS), where all time pairs share identical correlation \rho. An Autoregressive AR(1) structure allows correlation to decay exponentially with time separation \Delta t:

\operatorname{Cor}(y_{ij}, y_{ik}) = \phi^{|t_{ij} - t_{ik}|}

We compare CS versus AR(1) on IDHC using Generalized Least Squares (nlme::gls):

Code 
df_idhc <- df_prot[df_prot$Protein == "IDHC", ]
df_idhc$Time <- as.numeric(as.character(df_idhc$GROUP))

# Fit Compound Symmetry
m_cs  <- gls(LogIntensities ~ Time, 
             correlation = corCompSymm(form = ~ 1 | SUBJECT), 
             data = df_idhc)

# Fit First-Order Autoregressive AR(1)
m_ar1 <- gls(LogIntensities ~ Time, 
             correlation = corAR1(form = ~ Time | SUBJECT), 
             data = df_idhc)

cat(sprintf("Compound Symmetry:   AIC = %.2f | Estimated Rho = %.4f\n",
            AIC(m_cs), coef(m_cs$modelStruct$corStruct, unconstrained = FALSE)))
Compound Symmetry:   AIC = 102.30 | Estimated Rho = -0.1027
Code 
cat(sprintf("Autoregressive AR(1): AIC = %.2f | Estimated Phi = %.4f\n",
            AIC(m_ar1), coef(m_ar1$modelStruct$corStruct, unconstrained = FALSE)))
Autoregressive AR(1): AIC = 97.54 | Estimated Phi = 0.5537
NoteInterpreting Negative Correlation in Compound Symmetry

The slight negative estimated correlation for Compound Symmetry (\hat{\rho} = -0.1027) reflects very weak culture-to-culture baseline clustering for IDHC (consistent with the 0% SUBJECT variance extracted in Step 6), representing a known boundary artifact in REML estimation when the true between-cluster variance approaches zero. In contrast, the first-order autoregressive AR(1) structure captures genuine temporal decay (\hat{\phi} = 0.5537) across sequentially sampled timepoints, yielding a substantially superior AIC (97.54 vs. 102.30).

21.9 Step 5: REML vs. ML Variance Estimation in lme4

Standard Maximum Likelihood (ML) estimates variance components while ignoring degrees of freedom consumed by fixed effects (p). In small cohorts (n = 30, p = 2), ML underestimates residual variance by the factor \frac{n - p}{n}. Restricted Maximum Likelihood (REML) eliminates this bias:

Code 
fit_reml <- lmer(LogIntensities ~ Time + (1 | SUBJECT), data = df_idhc, REML = TRUE)
fit_ml   <- lmer(LogIntensities ~ Time + (1 | SUBJECT), data = df_idhc, REML = FALSE)

cat(sprintf("REML residual sigma: %.4f\n", sigma(fit_reml)))
REML residual sigma: 1.1818
Code 
cat(sprintf("ML   residual sigma: %.4f\n", sigma(fit_ml)))
ML   residual sigma: 1.1417
Code 
cat(sprintf("Ratio (REML / ML):   %.6f\n", sigma(fit_reml) / sigma(fit_ml)))
Ratio (REML / ML):   1.035098

cat(sprintf("Theoretical factor sqrt(n / (n - p)): %.6f\n", sqrt(30 / (30 - 2))))

The empirical ratio matches the exact theoretical correction \sqrt{30 / 28} = 1.035098. REML provides less biased variance components, preventing false-positive inflation in small-sample MS proteomics.

21.12 Step 8: Paired and Blocked Designs with limma

When biological replicates or patient cohorts are sampled across paired conditions (e.g., baseline vs. diauxic shift), blocking on the biological replicate removes inter-replicate baseline variability:

Code 
# Subset data to paired comparison: T1 (exponential) vs T7 (diauxic shift)
pair_meta <- meta_df[meta_df$Time_fac %in% c("1", "7"), ]
pair_meta$Time_fac <- droplevels(pair_meta$Time_fac)
pair_expr <- expr_mat[, rownames(pair_meta)]

# Method 1: Fixed-effect blocking in design matrix
design_blocked <- model.matrix(~ Time_fac + SUBJECT, data = pair_meta)
fit_blocked <- lmFit(pair_expr, design_blocked) |> eBayes()
res_blocked <- topTable(fit_blocked, coef = "Time_fac7", number = Inf)

# Method 2: Duplicate correlation (random-effects blocking)
design_simple <- model.matrix(~ Time_fac, data = pair_meta)
corfit <- duplicateCorrelation(pair_expr, design_simple, block = pair_meta$SUBJECT)
fit_dup <- lmFit(pair_expr, design_simple, block = pair_meta$SUBJECT, correlation = corfit$consensus) |> eBayes()
res_dup <- topTable(fit_dup, coef = "Time_fac7", number = Inf)

21.14 The Five Deadly Sins of Repeated-Measures MS Analysis

  1. Pseudoreplication: Treating multiple runs from the same patient or culture as independent observations. Remedy: Include random subject intercepts (1 | subject) or block on subject.
  2. Wald Tests on Small Clusters: Relying on asymptotic Wald z-tests when n < 30. Remedy: Always use Kenward-Roger degrees-of-freedom adjustment (ddf = "Kenward-Roger" in dream).
  3. REML for Fixed-Effects Model Selection: Using REML likelihood ratio tests to compare models with different fixed effects. Remedy: Fit models with standard ML (REML = FALSE) when performing LRTs on nested fixed effects.
  4. Overfitting High-Degree Polynomials: Using 5th- or 6th-order polynomials to model time courses, causing wild boundary oscillations (Runge’s phenomenon). Remedy: Use natural cubic splines with boundary knot linear constraints (splines::ns(Time, df = 3)).
  5. Omitting Empirical Bayes Moderation in High-Dimensional Omics: Estimating separate unmoderated mixed models feature-by-feature when testing thousands of biomolecules. Remedy: When sample size per condition is modest (n < 30), individual feature variances fluctuate erratically due to limited denominator degrees of freedom; deploy Empirical Bayes moderation via variancePartition::dream to shrink per-feature variances toward a consensus prior trend, while the total feature count p separately drives multiple-testing (FDR) control.

  n <- nrow(X); q <- ncol(Z)
  R_inv <- diag(1 / sigma_e^2, n)

# Modeling Covariates and Repeated Measures for MS Data

> *"A two‑group t‑test is rarely enough. Real MS experiments have batches, paired samples, and repeated measurements. Ignoring these structures inflates false positives and invalidates statistical inference."*

Real mass spectrometry studies are intrinsically structured: identical biological replicates sampled longitudinally across a metabolic transition, cell lines processed in distinct instrument batches, and clinical covariates (age, sex, BMI) confounding primary experimental factors. Treating correlated, repeated measurements as independent samples artificially deflates standard errors, creates pseudoreplication, and manufactures spurious discoveries. This chapter demonstrates how to formally model experimental structure using linear mixed-effects models, variance partitioning, and empirical Bayes shrinkage in R—transforming raw longitudinal MS data into robust, reproducible biological conclusions.

::: {.callout-warning title="The One Mistake to Avoid"}
**Treating repeated measures as independent samples (pseudoreplication).** Paired or longitudinal data analyzed as if independent inflates nominal degrees of freedom, severely narrows confidence intervals, and drives false-positive rates beyond 50%. Always account for intra-subject or intra-replicate correlation using random intercepts, blocking, or specialized covariance structures.
:::

## Why Modeling Structure Matters for MS Data

Mass spectrometry experiments rarely conform to simple independent two-group comparisons. In real cohorts, variance arises from multiple biological and technical strata:

| Structure | Example in MS Proteomics/Metabolomics | Ignoring It Causes |
|------------------|-----------------------------------|-------------------------------|
| **Batch effects** | Samples run across different instrument days or LC columns | Spurious biomarker discoveries confounded by run order |
| **Paired design** | Identical patient sampled before and after therapeutic intervention | Loss of statistical power; between-subject heterogeneity unmodeled |
| **Repeated measures** | 10-timepoint metabolic transition time-course across biological replicates | Severe pseudoreplication; inflated type-I error ($p$-value deflation) |
| **Confounders** | Age, sex, and body mass index in clinical biofluids | Biased effect size estimates for primary disease contrasts |
| **Factorial design** | Genotype × Time or Drug × Dose interactions | Failure to detect conditional kinetics (e.g., drug active only at late times) |

### The Intraclass Correlation Coefficient (ICC)

When individual biological units (patients, cultures, animals) are measured repeatedly across $T$ time points, intra-subject observations share baseline variance. The **Intraclass Correlation Coefficient (ICC)** quantifies the proportion of total variance attributable to between-subject differences:

$$\rho = \frac{\sigma^2_b}{\sigma^2_b + \sigma^2_e}$$

where $\sigma^2_b$ denotes the between-subject variance and $\sigma^2_e$ represents within-subject residual noise.

For example, in a cohort of $N = 10$ patients sampled at $T = 4$ timepoints ($n_{\text{total}} = 40$) with an ICC of $\rho = 0.60$, the effective sample size is only:

$$n_{\text{eff}} = \frac{40}{1 + 3(0.60)} = \frac{40}{2.80} \approx 14.3$$

An unblocked naive $t$-test assumes 38 degrees of freedom ($n_{\text{total}} - 2$), whereas the true effective sample size supports only $\sim 12$ ($n_{\text{eff}} - 2$). The $\sim 26$ excess degrees of freedom represent severe statistical inflation, severely narrowing confidence intervals and producing falsely significant discoveries.

### Linear Mixed Models (LMM) vs. GEE

Two principal paradigms exist for handling correlated MS data:

| Criterion | Linear Mixed-Effects Models (`lme4`, `dream`) | Generalized Estimating Equations (`geepack`) |
|------------------|-----------------------------------|-------------------------------|
| **Inference Target** | Subject-specific (conditional) | Population-averaged (marginal) |
| **Missing Data** | Valid under Missing at Random (MAR) | Requires Missing Completely at Random (MCAR) |
| **Small Samples** | Exact small-sample degrees-of-freedom corrections (Kenward-Roger) | Requires large cluster counts ($n \ge 30$) for sandwich variance stability |
| **High-Throughput** | Integrated with Empirical Bayes moderation (`variancePartition::dream`) | Computationally cumbersome across thousands of features |

For mass spectrometry, **linear mixed-effects models moderated by empirical Bayes** are the gold standard.

## Step 3: Repeated Measures Modeling with `variancePartition::dream`

In standard linear models, degrees of freedom are $N - p$. In repeated-measures mixed models with small cluster counts, exact distributions do not exist. The **Kenward-Roger (KR)** adjustment computes an adjusted covariance matrix for fixed effects that accounts for small-sample variance-component estimation error and derives Satterthwaite-type effective degrees of freedom.

The `dream` engine in `variancePartition` (Hoffman & Roussos, 2021) fits linear mixed models across all proteins in parallel, applying Kenward-Roger DDF and borrowing information across features via Empirical Bayes shrinkage.

```{r}
# Formula with fixed timepoints and random replicate intercept

# Formulate contrasts for key transitions using makeContrastsDream:
# Diauxic Shift (T7 vs T1) and Stationary Phase (T10 vs T1)
L <- makeContrastsDream(form, meta_df, 
                        contrasts = c(Diauxic_T7_vs_T1     = "Time_fac7 - Time_fac1",
                                      Stationary_T10_vs_T1 = "Time_fac10 - Time_fac1"))

# Fit dream mixed model with Kenward-Roger DDF
fit_mm <- dream(expr_mat, form, meta_df, L = L, ddf = "Kenward-Roger")
fit_eb <- eBayes(fit_mm)

res_diauxic   <- variancePartition::topTable(fit_eb, coef = "Diauxic_T7_vs_T1", number = Inf)
```

## Step 4: Comparing Covariance Structures in `nlme`

In longitudinal studies, observations close in time are often more correlated than observations distant in time. A standard random-intercept model imposes **Compound Symmetry (CS)**, where all time pairs share identical correlation $\rho$. An **Autoregressive AR(1)** structure allows correlation to decay exponentially with time separation $\Delta t$:

$$\operatorname{Cor}(y_{ij}, y_{ik}) = \phi^{|t_{ij} - t_{ik}|}$$

We compare CS versus AR(1) on IDHC using Generalized Least Squares (`nlme::gls`):

```{r}
df_idhc <- df_prot[df_prot$Protein == "IDHC", ]
df_idhc$Time <- as.numeric(as.character(df_idhc$GROUP))

# Fit Compound Symmetry
m_cs  <- gls(LogIntensities ~ Time, 
             correlation = corCompSymm(form = ~ 1 | SUBJECT), 
             data = df_idhc)

# Fit First-Order Autoregressive AR(1)
m_ar1 <- gls(LogIntensities ~ Time, 
             correlation = corAR1(form = ~ Time | SUBJECT), 
             data = df_idhc)

cat(sprintf("Compound Symmetry:   AIC = %.2f | Estimated Rho = %.4f\n",
            AIC(m_cs), coef(m_cs$modelStruct$corStruct, unconstrained = FALSE)))
cat(sprintf("Autoregressive AR(1): AIC = %.2f | Estimated Phi = %.4f\n",
            AIC(m_ar1), coef(m_ar1$modelStruct$corStruct, unconstrained = FALSE)))
```

::: {.callout-note title="Interpreting Negative Correlation in Compound Symmetry"}
The slight negative estimated correlation for Compound Symmetry ($\hat{\rho} = -0.1027$) reflects very weak culture-to-culture baseline clustering for IDHC (consistent with the 0% `SUBJECT` variance extracted in Step 6), representing a known boundary artifact in REML estimation when the true between-cluster variance approaches zero. In contrast, the first-order autoregressive AR(1) structure captures genuine temporal decay ($\hat{\phi} = 0.5537$) across sequentially sampled timepoints, yielding a substantially superior AIC (97.54 vs. 102.30).
:::

## Step 5: REML vs. ML Variance Estimation in `lme4`

Standard Maximum Likelihood (ML) estimates variance components while ignoring degrees of freedom consumed by fixed effects ($p$). In small cohorts ($n = 30, p = 2$), ML underestimates residual variance by the factor $\frac{n - p}{n}$. Restricted Maximum Likelihood (REML) eliminates this bias:

```{r}
fit_reml <- lmer(LogIntensities ~ Time + (1 | SUBJECT), data = df_idhc, REML = TRUE)
fit_ml   <- lmer(LogIntensities ~ Time + (1 | SUBJECT), data = df_idhc, REML = FALSE)

cat(sprintf("REML residual sigma: %.4f\n", sigma(fit_reml)))
cat(sprintf("ML   residual sigma: %.4f\n", sigma(fit_ml)))
cat(sprintf("Ratio (REML / ML):   %.6f\n", sigma(fit_reml) / sigma(fit_ml)))
cat(sprintf("Theoretical factor sqrt(n / (n - p)): %.6f\n", sqrt(30 / (30 - 2))))
```

The empirical ratio matches the exact theoretical correction $\sqrt{30 / 28} = 1.035098$. REML provides less biased variance components, preventing false-positive inflation in small-sample MS proteomics.

## The Five Deadly Sins of Repeated-Measures MS Analysis

1.  **Pseudoreplication:** Treating multiple runs from the same patient or culture as independent observations. *Remedy:* Include random subject intercepts `(1 | subject)` or block on subject.
2.  **Wald Tests on Small Clusters:** Relying on asymptotic Wald $z$-tests when $n < 30$. *Remedy:* Always use Kenward-Roger degrees-of-freedom adjustment (`ddf = "Kenward-Roger"` in `dream`).
3.  **REML for Fixed-Effects Model Selection:** Using REML likelihood ratio tests to compare models with different fixed effects. *Remedy:* Fit models with standard ML (`REML = FALSE`) when performing LRTs on nested fixed effects.
4.  **Overfitting High-Degree Polynomials:** Using 5th- or 6th-order polynomials to model time courses, causing wild boundary oscillations (Runge's phenomenon). *Remedy:* Use natural cubic splines with boundary knot linear constraints (`splines::ns(Time, df = 3)`).
5.  **Omitting Empirical Bayes Moderation in High-Dimensional Omics:** Estimating separate unmoderated mixed models feature-by-feature when testing thousands of biomolecules. *Remedy:* When sample size per condition is modest ($n < 30$), individual feature variances fluctuate erratically due to limited denominator degrees of freedom; deploy Empirical Bayes moderation via `variancePartition::dream` to shrink per-feature variances toward a consensus prior trend, while the total feature count $p$ separately drives multiple-testing (FDR) control.

### Exercise 2: Positive-Definiteness of Henderson's Mixed Model Coefficient Matrix
In Henderson's Mixed Model Equations, the coefficient matrix $\mathbf{C}$ is given by:

$$\mathbf{C} = \begin{bmatrix} \mathbf{X}^T \mathbf{R}^{-1} \mathbf{X} & \mathbf{X}^T \mathbf{R}^{-1} \mathbf{Z} \\ \mathbf{Z}^T \mathbf{R}^{-1} \mathbf{X} & \mathbf{Z}^T \mathbf{R}^{-1} \mathbf{Z} + \mathbf{G}^{-1} \end{bmatrix}$$

Write a base R function to verify that $\mathbf{C}$ is strictly positive-definite ($\det(\mathbf{C}) > 0$ and all eigenvalues $> 0$):

```{r}
# Base R MME Positive-Definiteness Checker
check_henderson_pd <- function(X, Z, sigma_b, sigma_e) {
  n <- nrow(X); q <- ncol(Z)
  R_inv <- diag(1 / sigma_e^2, n)
  G_inv <- diag(1 / sigma_b^2, q)
  
  C11 <- t(X) %*% R_inv %*% X
  C12 <- t(X) %*% R_inv %*% Z
  C21 <- t(Z) %*% R_inv %*% X
  C22 <- t(Z) %*% R_inv %*% Z + G_inv
  
  C <- rbind(cbind(C11, C12), cbind(C21, C22))
  eigenvals <- eigen(C, symmetric = TRUE, only.values = TRUE)$values
  
  list(
    is_positive_definite = all(eigenvals > 0),
    min_eigenvalue = min(eigenvals),
    condition_number = max(eigenvals) / min(eigenvals)
  )
}

# Test on 4-observation toy block
X_toy <- matrix(c(1, 1, 1, 1), ncol = 1)
Z_toy <- matrix(c(1, 1, 0, 0, 0, 0, 1, 1), ncol = 2)
check_henderson_pd(X_toy, Z_toy, sigma_b = 1.0, sigma_e = 1.0)
```

## Summary

In mass spectrometry experiments with longitudinal profiles, batches, or paired designs:
- Naive standard errors severely inflate false-positive rates due to pseudoreplication.
- **`variancePartition::dream`** provides an end-to-end framework combining linear mixed models, Kenward-Roger small-sample adjustments, and Empirical Bayes moderation across feature tables.
- **Variance partitioning** diagnoses whether experimental variation is driven by biological conditions or unwanted technical batches before downstream biological claims are made.
- **Natural cubic splines** capture continuous non-linear biological kinetics without polynomial boundary instability.
