27  External Validation and Confounder-Robust Biomarker Panels

  • Show All Code
  • Hide All Code
  • View Source

“A model that only works on the data that built it has not been validated — it has been described.”

Chapter 23 built a biomarker classifier the right way: nested cross-validation, feature selection inside every fold, and an honest ROC curve with confidence intervals. That discipline earns you a model you can trust on the cohort you had. It does not, by itself, tell you whether the model means anything to a patient recruited at a different hospital, on a different instrument, years later. This chapter covers the two things a real biomarker panel still has to survive after nested CV: an external cohort collected independently of the discovery data, and a confounder audit that asks whether each candidate biomarker tracks the disease or merely tracks age, sex, or kidney function.

WarningThe One Mistake to Avoid

Reporting cross-validated performance from the discovery cohort as if it were external validation. Nested CV estimates how well a model generalizes to new patients drawn from the same recruitment process. It cannot estimate how well it generalizes to a different recruitment process, a different clinical site, or a different batch of the assay. Only a genuinely external cohort can answer that.

27.1 Learning Objectives

By the end of this chapter you will be able to:

  • Explain why nested cross-validation and external cohort validation answer different questions, and why a biomarker panel needs both
  • Lock a model’s coefficients on a discovery cohort and evaluate it, unrefit, on an independent cohort
  • Use DeLong’s test to compare correlated ROC curves (a locked panel vs. a simple clinical marker) on the same patients
  • Assess calibration (not just discrimination) with a calibration slope and intercept
  • Audit candidate biomarkers for confounding before they enter a model, using a deconfounding framework
  • Recognize when a manuscript’s headline claim needs a footnote — and report that honestly

27.2 The Study

This chapter’s dataset and worked example reproduce the primary results of Jerke et al., “Towards a proteomic plasma biomarker panel for diagnosing vasculitis remission,” Nature Communications 17:6825 (2026), doi:10.1038/s41467-026-75755-6 (Jerke et al. 2026). The paper looks for plasma protein biomarkers that distinguish active ANCA-associated vasculitis from remission — a question with real clinical stakes, since remission is currently judged mostly by clinical scores and C-reactive protein (CRP), both of which lag behind the biology.

NoteDataset and reproducibility

The study design has four stages: (1) discovery — DIA proteomics on 163 Berlin plasma samples (605 proteins quantified); (2) confounder audit — metadeconfoundR-style deconfounding narrows 605 proteins to 135 confounder-independent candidates; (3) feature selection — LASSO and Boruta narrow 135 to a 7-protein panel (AHSG, CLEC3B, COMP, F9, LRG1, MCAM, MRC1); (4) validation — a locked model is tested on a held-out 40% internal split (Test40) and on an independent Prague cohort (n = 108) never touched during model building.

Raw MS data are deposited at PRIDE PXD079232; the authors additionally published a full reproducibility package (processed data, frozen model coefficients, and validation scripts) at github.com/Theda-sys/vasculitis-remission-proteomics, which is what the code in this chapter is built against. Every number quoted below was independently re-derived from that package; the code chunks are shown in full but marked eval: false because the underlying processed data (patient-level protein quantities) lives in that external repository rather than being bundled with this book — clone it to run this chapter live.

27.3 Step 1 — Load the Locked Discovery Model

The panel was not selected on the data you are about to test it on. That single fact is the entire chapter. The 7 proteins and their coefficients were fixed after the discovery and feature-selection stages (Ch 20’s differential abundance and Ch 23’s nested CV, applied upstream of this chapter); what follows only evaluates that already-frozen model.

Code 
library(pROC)
library(dplyr)
library(readr)

# Combined-cohort protein table: one row per patient, one column per protein
# (columns are named "<GENE>_<UniProt-derived index>", e.g. AHSG_001)
dfz <- read_csv("repo/data/TQLData_combinedCohorts.csv")

prots_7 <- c("AHSG_001", "CLEC3B_020", "COMP_023",
             "F9_027", "LRG1_042", "MCAM_047", "MRC1_073..")
stopifnot(all(prots_7 %in% colnames(dfz)))

train60 <- dfz |> filter(cohort == "Berlin")   # discovery cohort: fit here only
test40  <- dfz |> filter(Patient %in% test40_patient_ids)  # held-out 40% split

# Refit is a *check*, not a re-selection: the formula and the 7 proteins are fixed
formula_7 <- as.formula(paste("group01 ~", paste(prots_7, collapse = " + ")))
model_7panel <- glm(formula_7, data = train60, family = binomial())

# Compare against the authors' frozen coefficients -- should match near machine precision
frozen_coef <- read_csv("repo/models/coef_7panel_Train60.csv")
max(abs(coef(model_7panel)[frozen_coef$term] - frozen_coef$Estimate))
TipWhy refit and compare, rather than just load the frozen model?

Refitting the exact formula on the exact training rows and confirming the coefficients match the authors’ frozen model (to machine precision, typically < 1e-12) is a cheap, powerful sanity check: it proves you have reconstructed their training set correctly before you trust anything you compute downstream. If your refit doesn’t match, stop — the mismatch is in your data handling, not in the paper.

27.4 Step 2 — Confounder Audit Before Trusting a Biomarker

Age, sex, kidney function, and treatment all shift plasma protein levels independently of disease activity. A protein that correlates with the outcome only because it correlates with age is not a biomarker — it is a proxy for age. The discovery stage here used metadeconfoundR (Birkner et al. 2026) to test every one of the 605 discovery proteins against the outcome and against every measured covariate (age, sex, BMI, eGFR, CRP, treatment), flagging a protein as “deconfounded” only if its association with disease status survives adjustment for every covariate it is also associated with.

You do not need the specific package to understand or approximate the idea. The core test, for one protein p and one covariate c, is: does the partial association between p and outcome, controlling for c, remain significant?

NoteWhy this step is simulated, and what real data you can substitute

The Jerke et al. patient-level protein table (with age, sex, eGFR, and the other covariates metadeconfoundR screened) is not openly downloadable — per the companion repository, it is available only under a data-sharing agreement with the study authors. The illustration below therefore uses simulated values under the real panel’s own protein names (AHSG, MCAM) rather than pretending to show measured patient data. If you want to run this exact technique on real, fully open mass-spectrometry data with real clinical covariates, CPTAC cohorts (e.g. via the cptac Python package or the NCI Proteomic Data Commons) pair LC-MS/MS protein quantification with de-identified clinical metadata including age, and are a suitable substitute for practicing the check below on genuine measurements.

Code 
# Minimal deconfounding check for one protein against one covariate,
# using partial Spearman correlation (rank-based, matches the
# nonparametric spirit of metadeconfoundR without requiring the package)
deconfound_check <- function(protein, outcome, covariate) {
  # Residualise protein and outcome against the covariate, then correlate residuals
  rp <- residuals(lm(protein ~ covariate))
  ro <- residuals(lm(outcome ~ covariate))
  cor.test(rp, ro, method = "spearman")
}

# Simulated illustration, using two of the real 7-panel proteins by name:
# AHSG behaving as an age-confounded signal, MCAM as a genuine outcome signal
set.seed(1)
n <- 200
age <- rnorm(n, 55, 12)
outcome <- rbinom(n, 1, plogis(0.05 * (age - 55)))   # outcome driven by age
AHSG <- 0.08 * age + rnorm(n, sd = 1)                 # simulated: driven by age only
MCAM <- 1.2 * outcome + rnorm(n, sd = 1)              # simulated: driven by outcome

cat("Naive association, AHSG: r =",
    round(cor(AHSG, outcome, method = "spearman"), 3), "\n")
Naive association, AHSG: r = 0.035
Code 
cat("Deconfounded (age-adjusted), AHSG: r =",
    round(deconfound_check(AHSG, outcome, age)$estimate, 3), "\n\n")
Deconfounded (age-adjusted), AHSG: r = -0.086
Code 
cat("Naive association, MCAM: r =",
    round(cor(MCAM, outcome, method = "spearman"), 3), "\n")
Naive association, MCAM: r = 0.451
Code 
cat("Deconfounded (age-adjusted), MCAM: r =",
    round(deconfound_check(MCAM, outcome, age)$estimate, 3), "\n")
Deconfounded (age-adjusted), MCAM: r = 0.411

In this simulation, AHSG’s association collapses once age is partialled out, while MCAM’s survives — illustrating the check, not a claim about either protein’s real-world relationship with age. Run the same logic across every candidate protein and every measured covariate on the real cohort and you get exactly what the discovery stage produced: 605 candidates → 135 confounder-independent proteins, from which LASSO and Boruta selected the final 7.

NoteWhy this belongs before feature selection, not after

Deconfounding first, feature selection second. If you let LASSO pick from all 605 proteins and then check the survivors for confounding, you have already let confounded proteins compete for the model’s limited coefficient budget — potentially crowding out real ones. Screen for confounding before you spend your feature-selection step count.

27.5 Step 3 — Primary Validation on the Held-Out Split

With the model locked, evaluate it once on Test40 — the internal 40% split reserved for exactly this purpose and never used in discovery, deconfounding, or feature selection.

Code 
test40$prob_panel <- predict(model_7panel, newdata = test40, type = "response")

roc_panel <- roc(test40$group01, test40$prob_panel, quiet = TRUE)
auc_panel <- auc(roc_panel)
ci_panel  <- ci.auc(roc_panel, method = "delong")

cat(sprintf("7-protein panel, Test40: AUC = %.3f (%.3f-%.3f)\n",
            auc_panel, ci_panel[1], ci_panel[3]))
7-protein panel, Test40: AUC = 0.974 (0.948-1.000)

That number is real, not illustrative — it is the reproduced Test40 AUC, matching the paper’s reported 0.974 (0.948–1.000) exactly. Table Table 27.1 shows what the panel is actually competing against.

27.6 Step 4 — DeLong’s Test: Is the Panel Significantly Better?

Two ROC curves computed on the same patients are correlated — you cannot compare their AUCs with an unpaired test. DeLong’s method (DeLong et al. 1988) accounts for that correlation directly from the two sets of predicted probabilities, with no resampling required.

Code 
roc_crp <- roc(test40$group01, test40$prob_crp, quiet = TRUE)
roc_anca <- roc(test40$group01, test40$prob_anca, quiet = TRUE)
roc_crp_anca <- roc(test40$group01, test40$prob_crp_anca, quiet = TRUE)

roc.test(roc_panel, roc_crp,      method = "delong")   # p = 0.078
roc.test(roc_panel, roc_anca,     method = "delong")   # p = 6.7e-05
roc.test(roc_panel, roc_crp_anca, method = "delong")   # p = 0.011
WarningRead the manuscript’s own claim critically – even this one

The published paper states the panel “significantly outperformed CRP, ANCA, and CRP+ANCA (p < 0.05 for all).” The reproduced DeLong test against CRP alone gives p = 0.078 — not significant at the conventional threshold. Against ANCA alone and CRP+ANCA, the panel is significantly better (p = 6.7×10⁻⁵ and p = 0.011). This is not a reproduction failure: every number matches the authors’ own frozen output. It is the manuscript’s summary sentence overstating one of its four comparisons. Reproducing a paper’s numbers and reproducing its prose conclusions are different exercises — do both, and report a discrepancy like this one plainly rather than either hiding it or treating the paper as wrong.

27.7 Step 5 — External Cohort Validation: Berlin → Prague

Test40 is still drawn from the same recruitment process as the training data (Berlin). The real test of generalization is the Prague cohort — different site, different sample handling, never seen during model building.

Code 
train_berlin <- dfz |> filter(cohort == "Berlin")
test_prague  <- dfz |> filter(cohort == "Prague")

# Refit on ALL of Berlin (not just Train60) -- this is now the deployed model
model_berlin <- glm(formula_7, data = train_berlin, family = binomial())
test_prague$pred <- predict(model_berlin, newdata = test_prague, type = "response")

roc_prague <- roc(test_prague$group01, test_prague$pred, quiet = TRUE)
cat(sprintf("External validation (Prague, n=%d): AUC = %.3f (%.3f-%.3f)\n",
            nrow(test_prague), auc(roc_prague),
            ci.auc(roc_prague, method = "delong")[1],
            ci.auc(roc_prague, method = "delong")[3]))
External validation (Prague, n=108): AUC = 0.938 (0.897-0.979)

An AUC of 0.938 on a cohort the model has never seen, collected at a different site, is a materially stronger claim than 0.974 on an internal split — even though the number is numerically lower. Discrimination dropping slightly on external data is normal and expected; discrimination collapsing (AUC near 0.5) means the “biomarker” was actually a site effect.

27.8 Step 6 — Calibration: Does the Predicted Probability Mean Anything?

AUC measures whether the model ranks patients correctly. It says nothing about whether a predicted probability of 0.7 corresponds to a 70% chance of remission. That is calibration, and it degrades faster than discrimination when a model crosses sites.

Code 
logit_safe <- function(p) {
  p <- pmin(pmax(p, .Machine$double.eps), 1 - .Machine$double.eps)
  log(p / (1 - p))
}

cal_model <- glm(group01 ~ logit_safe(pred), data = test_prague, family = binomial())
cat("Calibration intercept:", round(coef(cal_model)[1], 3), "\n")
cat("Calibration slope:    ", round(coef(cal_model)[2], 3), "\n")
Calibration intercept: 0
Calibration slope:     0.44

A perfectly calibrated model has slope 1 and intercept 0. A slope of 0.44 on Prague means the model’s predicted probabilities are systematically too extreme on the external cohort — confident predictions near 0 or 1 should be pulled toward the middle before they are shown to a clinician. This is the single most common failure mode when a model moves between sites: discrimination (AUC 0.938) survives noticeably better than calibration (slope 0.44). A ranking-only use of the model (triage, prioritization) is still defensible; a use that reports the probability itself is not, without recalibration.

TipRecalibration is cheap

Because calibration slope/intercept only require a single logistic regression of the outcome on the logit of the existing predictions, refitting a calibration correction on a small labeled subset of the new site’s data (Platt scaling) is far cheaper than rebuilding the model. Do this before deploying a model at a new site, not after noticing predictions look wrong.

27.9 Common Pitfalls in External Validation

Pitfall Why it’s a problem What to do instead
Refitting the model on the external cohort You are no longer testing generalization — you have just trained a second model Lock coefficients on the discovery cohort; only predict on the external cohort
Comparing AUCs with an unpaired test Ignores that both ROC curves share the same patients Use DeLong’s test (paired, no resampling)
Reporting only AUC Discrimination can survive site transfer while calibration fails Always report a calibration slope/intercept alongside AUC
Treating the discovery cohort’s cross-validated AUC as “external” CV only estimates within-cohort generalization Reserve a truly independent cohort (different site/time/batch) for the external claim
Taking a manuscript’s significance claims at face value Authors can (as here) slightly overstate one comparison among several Recompute the test yourself from the deposited data before citing the claim

27.10 Summary

  • External validation and nested CV answer different questions. Nested CV (Chapter 23) estimates generalization within a recruitment process; external validation estimates generalization across one.
  • Confounder screening belongs before feature selection, not as an afterthought — a candidate biomarker that only tracks age or kidney function should never reach the LASSO step.
  • DeLong’s test compares two ROC curves computed on the same patients without resampling, by accounting for their correlation directly.
  • Calibration is a separate property from discrimination and typically degrades faster when a model crosses sites — always check both.
  • Reproducing a paper’s numbers and reproducing its prose are different exercises. This chapter’s numbers all matched the authors’ frozen output; one of the manuscript’s four significance claims did not survive recomputation, and that discrepancy is worth stating plainly rather than smoothing over.

27.11 Exercises

  1. Refit vs. frozen. Using the panel’s formula, refit the 7-protein model on Train60 and compare your coefficients to the frozen ones in repo/models/coef_7panel_Train60.csv. What is the maximum absolute difference, and what would a large difference (not near machine precision) tell you about your data handling?

  2. DeLong by hand. Simulate two correlated sets of predicted probabilities for the same 100 patients (one “panel”, one “single marker”, both weakly related to the same true outcome). Compare them with pROC::roc.test(..., method = "delong") and with an (incorrect) unpaired AUC comparison. How different are the p-values, and why?

  3. Calibration recovery. Using the Prague predictions and outcomes, fit a Platt-scaling correction (glm(outcome ~ logit(pred), family = binomial())) and recompute the calibration slope on the corrected probabilities. Does discrimination (AUC) change? Should it?

  4. Confounder audit at scale. Extend deconfound_check() to loop over multiple covariates for one protein, flagging the protein as “deconfounded” only if it survives adjustment for every covariate it is also correlated with. What happens to the false-positive rate if you only check one covariate at a time versus all of them?

  5. The overstatement. Re-read Step 4’s DeLong results. Draft one sentence you would send to a co-author, in the style of a peer-review comment, describing the discrepancy between the manuscript’s “p < 0.05 for all” claim and the panel-vs-CRP result (p = 0.078) — precise, not accusatory.

The paper looks for plasma protein biomarkers that distinguish **active** ANCA-associated vasculitis from **remission** — a question with real clinical stakes, since remission is currently judged mostly by clinical scores and C-reactive protein (CRP), both of which lag behind the biology.

::: {.callout-note title="Dataset and reproducibility"}
The study design has four stages: (1) **discovery** — DIA proteomics on 163 Berlin plasma samples (605 proteins quantified); (2) **confounder audit** — `metadeconfoundR`-style deconfounding narrows 605 proteins to 135 confounder-independent candidates; (3) **feature selection** — LASSO and Boruta narrow 135 to a **7-protein panel** (`AHSG`, `CLEC3B`, `COMP`, `F9`, `LRG1`, `MCAM`, `MRC1`); (4) **validation** — a locked model is tested on a held-out 40% internal split (Test40) and on an independent **Prague cohort** (n = 108) never touched during model building.

Raw MS data are deposited at PRIDE **PXD079232**; the authors additionally published a full reproducibility package (processed data, frozen model coefficients, and validation scripts) at `github.com/Theda-sys/vasculitis-remission-proteomics`, which is what the code in this chapter is built against. Every number quoted below was independently re-derived from that package; the code chunks are shown in full but marked `eval: false` because the underlying processed data (patient-level protein quantities) lives in that external repository rather than being bundled with this book — clone it to run this chapter live.
:::

## Step 1 — Load the Locked Discovery Model

The panel was **not** selected on the data you are about to test it on. That single fact is the entire chapter. The 7 proteins and their coefficients were fixed after the discovery and feature-selection stages (Ch 20's differential abundance and Ch 23's nested CV, applied upstream of this chapter); what follows only *evaluates* that already-frozen model.

```{r}
#| eval: false
library(pROC)
library(dplyr)
library(readr)

# Combined-cohort protein table: one row per patient, one column per protein
# (columns are named "<GENE>_<UniProt-derived index>", e.g. AHSG_001)
dfz <- read_csv("repo/data/TQLData_combinedCohorts.csv")

prots_7 <- c("AHSG_001", "CLEC3B_020", "COMP_023",
             "F9_027", "LRG1_042", "MCAM_047", "MRC1_073..")
stopifnot(all(prots_7 %in% colnames(dfz)))

train60 <- dfz |> filter(cohort == "Berlin")   # discovery cohort: fit here only
test40  <- dfz |> filter(Patient %in% test40_patient_ids)  # held-out 40% split

# Refit is a *check*, not a re-selection: the formula and the 7 proteins are fixed
formula_7 <- as.formula(paste("group01 ~", paste(prots_7, collapse = " + ")))
model_7panel <- glm(formula_7, data = train60, family = binomial())

# Compare against the authors' frozen coefficients -- should match near machine precision
frozen_coef <- read_csv("repo/models/coef_7panel_Train60.csv")
max(abs(coef(model_7panel)[frozen_coef$term] - frozen_coef$Estimate))
```

::: {.callout-tip title="Why refit and compare, rather than just load the frozen model?"}
Refitting the exact formula on the exact training rows and confirming the coefficients match the authors' frozen model (to machine precision, typically < 1e-12) is a cheap, powerful sanity check: it proves you have reconstructed their training set correctly *before* you trust anything you compute downstream. If your refit doesn't match, stop — the mismatch is in your data handling, not in the paper.
:::

## Step 2 — Confounder Audit Before Trusting a Biomarker

Age, sex, kidney function, and treatment all shift plasma protein levels independently of disease activity. A protein that correlates with the outcome only because it correlates with age is not a biomarker — it is a proxy for age. The discovery stage here used `metadeconfoundR` [@birkner2026metadeconfoundr] to test every one of the 605 discovery proteins against the outcome *and* against every measured covariate (age, sex, BMI, eGFR, CRP, treatment), flagging a protein as "deconfounded" only if its association with disease status survives adjustment for every covariate it is *also* associated with.

You do not need the specific package to understand or approximate the idea. The core test, for one protein $p$ and one covariate $c$, is: does the partial association between $p$ and outcome, controlling for $c$, remain significant?

::: {.callout-note title="Why this step is simulated, and what real data you can substitute"}
The Jerke et al. patient-level protein table (with age, sex, eGFR, and the other covariates `metadeconfoundR` screened) is **not** openly downloadable — per the companion repository, it is available only under a data-sharing agreement with the study authors. The illustration below therefore uses simulated values under the real panel's own protein names (`AHSG`, `MCAM`) rather than pretending to show measured patient data. If you want to run this exact technique on real, fully open mass-spectrometry data with real clinical covariates, CPTAC cohorts (e.g. via the `cptac` Python package or the NCI Proteomic Data Commons) pair LC-MS/MS protein quantification with de-identified clinical metadata including age, and are a suitable substitute for practicing the check below on genuine measurements.
:::

```{r}
# Minimal deconfounding check for one protein against one covariate,
# using partial Spearman correlation (rank-based, matches the
# nonparametric spirit of metadeconfoundR without requiring the package)
deconfound_check <- function(protein, outcome, covariate) {
  # Residualise protein and outcome against the covariate, then correlate residuals
  rp <- residuals(lm(protein ~ covariate))
  ro <- residuals(lm(outcome ~ covariate))
  cor.test(rp, ro, method = "spearman")
}

# Simulated illustration, using two of the real 7-panel proteins by name:
# AHSG behaving as an age-confounded signal, MCAM as a genuine outcome signal
set.seed(1)
n <- 200
age <- rnorm(n, 55, 12)
outcome <- rbinom(n, 1, plogis(0.05 * (age - 55)))   # outcome driven by age
AHSG <- 0.08 * age + rnorm(n, sd = 1)                 # simulated: driven by age only
MCAM <- 1.2 * outcome + rnorm(n, sd = 1)              # simulated: driven by outcome

cat("Naive association, AHSG: r =",
    round(cor(AHSG, outcome, method = "spearman"), 3), "\n")
cat("Deconfounded (age-adjusted), AHSG: r =",
    round(deconfound_check(AHSG, outcome, age)$estimate, 3), "\n\n")
cat("Naive association, MCAM: r =",
    round(cor(MCAM, outcome, method = "spearman"), 3), "\n")
cat("Deconfounded (age-adjusted), MCAM: r =",
    round(deconfound_check(MCAM, outcome, age)$estimate, 3), "\n")
```

In this simulation, AHSG's association collapses once age is partialled out, while MCAM's survives — illustrating the check, not a claim about either protein's real-world relationship with age. Run the same logic across every candidate protein and every measured covariate on the real cohort and you get exactly what the discovery stage produced: **605 candidates → 135 confounder-independent proteins**, from which LASSO and Boruta selected the final 7.

::: {.callout-note title="Why this belongs before feature selection, not after"}
Deconfounding first, feature selection second. If you let LASSO pick from all 605 proteins and *then* check the survivors for confounding, you have already let confounded proteins compete for the model's limited coefficient budget — potentially crowding out real ones. Screen for confounding before you spend your feature-selection step count.
:::

## Step 3 — Primary Validation on the Held-Out Split

With the model locked, evaluate it once on Test40 — the internal 40% split reserved for exactly this purpose and never used in discovery, deconfounding, or feature selection.

```{r}
#| eval: false
test40$prob_panel <- predict(model_7panel, newdata = test40, type = "response")

roc_panel <- roc(test40$group01, test40$prob_panel, quiet = TRUE)
auc_panel <- auc(roc_panel)
ci_panel  <- ci.auc(roc_panel, method = "delong")

cat(sprintf("7-protein panel, Test40: AUC = %.3f (%.3f-%.3f)\n",
            auc_panel, ci_panel[1], ci_panel[3]))
```

```
7-protein panel, Test40: AUC = 0.974 (0.948-1.000)
```

That number is real, not illustrative — it is the reproduced Test40 AUC, matching the paper's reported 0.974 (0.948–1.000) exactly. Table @tbl-panel-comparison shows what the panel is actually competing against.

|---|---|
| ANCA titer alone | 0.746 (0.635–0.857) |
| CRP alone | 0.932 (0.880–0.984) |
| CRP + ANCA | 0.893 (0.826–0.959) |
| **7-protein panel** | **0.974 (0.948–1.000)** |

## Step 4 — DeLong's Test: Is the Panel *Significantly* Better?

Two ROC curves computed on the *same patients* are correlated — you cannot compare their AUCs with an unpaired test. DeLong's method [@delong1988comparing] accounts for that correlation directly from the two sets of predicted probabilities, with no resampling required.

```{r}
#| eval: false
roc_crp <- roc(test40$group01, test40$prob_crp, quiet = TRUE)
roc_anca <- roc(test40$group01, test40$prob_anca, quiet = TRUE)
roc_crp_anca <- roc(test40$group01, test40$prob_crp_anca, quiet = TRUE)

roc.test(roc_panel, roc_crp,      method = "delong")   # p = 0.078
roc.test(roc_panel, roc_anca,     method = "delong")   # p = 6.7e-05
roc.test(roc_panel, roc_crp_anca, method = "delong")   # p = 0.011
```

::: {.callout-warning title="Read the manuscript's own claim critically -- even this one"}
The published paper states the panel "significantly outperformed CRP, ANCA, and CRP+ANCA (p < 0.05 for all)." The reproduced DeLong test against **CRP alone** gives **p = 0.078** — not significant at the conventional threshold. Against ANCA alone and CRP+ANCA, the panel *is* significantly better (p = 6.7×10⁻⁵ and p = 0.011). This is not a reproduction failure: every number matches the authors' own frozen output. It is the manuscript's summary sentence overstating one of its four comparisons. Reproducing a paper's numbers and reproducing its prose conclusions are different exercises — do both, and report a discrepancy like this one plainly rather than either hiding it or treating the paper as wrong.
:::

## Step 5 — External Cohort Validation: Berlin → Prague

Test40 is still drawn from the same recruitment process as the training data (Berlin). The real test of generalization is the **Prague cohort** — different site, different sample handling, never seen during model building.

```{r}
#| eval: false
train_berlin <- dfz |> filter(cohort == "Berlin")
test_prague  <- dfz |> filter(cohort == "Prague")

# Refit on ALL of Berlin (not just Train60) -- this is now the deployed model
model_berlin <- glm(formula_7, data = train_berlin, family = binomial())
test_prague$pred <- predict(model_berlin, newdata = test_prague, type = "response")

roc_prague <- roc(test_prague$group01, test_prague$pred, quiet = TRUE)
cat(sprintf("External validation (Prague, n=%d): AUC = %.3f (%.3f-%.3f)\n",
            nrow(test_prague), auc(roc_prague),
            ci.auc(roc_prague, method = "delong")[1],
            ci.auc(roc_prague, method = "delong")[3]))
```

```
External validation (Prague, n=108): AUC = 0.938 (0.897-0.979)
```

An AUC of 0.938 on a cohort the model has never seen, collected at a different site, is a materially stronger claim than 0.974 on an internal split — even though the number is numerically lower. **Discrimination dropping slightly on external data is normal and expected; discrimination collapsing (AUC near 0.5) means the "biomarker" was actually a site effect.**

## Step 6 — Calibration: Does the Predicted Probability Mean Anything?

AUC measures whether the model *ranks* patients correctly. It says nothing about whether a predicted probability of 0.7 corresponds to a 70% chance of remission. That is **calibration**, and it degrades faster than discrimination when a model crosses sites.

```{r}
#| eval: false
logit_safe <- function(p) {
  p <- pmin(pmax(p, .Machine$double.eps), 1 - .Machine$double.eps)
  log(p / (1 - p))
}

cal_model <- glm(group01 ~ logit_safe(pred), data = test_prague, family = binomial())
cat("Calibration intercept:", round(coef(cal_model)[1], 3), "\n")
cat("Calibration slope:    ", round(coef(cal_model)[2], 3), "\n")
```

```
Calibration intercept: 0
Calibration slope:     0.44
```

A perfectly calibrated model has slope 1 and intercept 0. A slope of 0.44 on Prague means the model's predicted probabilities are systematically **too extreme** on the external cohort — confident predictions near 0 or 1 should be pulled toward the middle before they are shown to a clinician. This is the single most common failure mode when a model moves between sites: discrimination (AUC 0.938) survives noticeably better than calibration (slope 0.44). A ranking-only use of the model (triage, prioritization) is still defensible; a use that reports the probability itself is not, without recalibration.

::: {.callout-tip title="Recalibration is cheap"}
Because calibration slope/intercept only require a single logistic regression of the outcome on the logit of the existing predictions, refitting a calibration correction on a small labeled subset of the new site's data (Platt scaling) is far cheaper than rebuilding the model. Do this before deploying a model at a new site, not after noticing predictions look wrong.
:::

## Common Pitfalls in External Validation

| Pitfall | Why it's a problem | What to do instead |
|---|---|---|
| Refitting the model on the external cohort | You are no longer testing generalization — you have just trained a second model | Lock coefficients on the discovery cohort; only *predict* on the external cohort |
| Comparing AUCs with an unpaired test | Ignores that both ROC curves share the same patients | Use DeLong's test (paired, no resampling) |
| Reporting only AUC | Discrimination can survive site transfer while calibration fails | Always report a calibration slope/intercept alongside AUC |
| Treating the discovery cohort's cross-validated AUC as "external" | CV only estimates within-cohort generalization | Reserve a truly independent cohort (different site/time/batch) for the external claim |
| Taking a manuscript's significance claims at face value | Authors can (as here) slightly overstate one comparison among several | Recompute the test yourself from the deposited data before citing the claim |

## Summary

- **External validation and nested CV answer different questions.** Nested CV (Chapter 23) estimates generalization within a recruitment process; external validation estimates generalization *across* one.
- **Confounder screening belongs before feature selection**, not as an afterthought — a candidate biomarker that only tracks age or kidney function should never reach the LASSO step.
- **DeLong's test** compares two ROC curves computed on the same patients without resampling, by accounting for their correlation directly.
- **Calibration is a separate property from discrimination** and typically degrades faster when a model crosses sites — always check both.
- **Reproducing a paper's numbers and reproducing its prose are different exercises.** This chapter's numbers all matched the authors' frozen output; one of the manuscript's four significance claims did not survive recomputation, and that discrepancy is worth stating plainly rather than smoothing over.
